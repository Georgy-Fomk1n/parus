## 3. Визуальные требования и брендбук

| Элемент | Требования |
| :--- | :--- |
| **Логотип** | Использовать строго в исходном виде. Изменение пропорций, цветов или начертания запрещено |
| **Цветовая палитра** | Использовать существующие фирменные цвета клуба. Допускается введение дополнительных акцентных цветов для кнопок CTA и бейджей при условии гармоничного сочетания с основной палитрой |
| **Типографика** | Использовать существующие фирменные шрифты. Допускается корректировка начертаний и размеров для улучшения читаемости на мобильных устройствах |
| **Настроение (Tone of Voice)** | Яркое, детское, игровое, вызывающее доверие. Избегать излишней строгости, но сохранять структурную чёткость |
| **Сетка и ритм** | Использовать 8-пиксельную сетку для согласованности отступов на всех устройствах |

### 3.1. Принципы работы с пользовательским контентом

Интерфейс должен предусматривать различные сценарии отображения пользовательского контента:
* изображения разного формата и пропорций;
* отсутствие изображения;
* загрузку контента;
* недостаточное качество исходного материала.

## 4. Требования к пользовательскому опыту (UX)

| Параметр | Решение |
| :--- | :--- |
| **Навигация** | Минималистичная, четыре пункта меню. Приоритет на быстрый доступ к каталогу и контактам |
| **Геопривязка** | Сайт общий для двух филиалов в районе Западное Дегунино. Выбор района на первом экране не требуется. Информация о филиалах размещается в разделе «О Клубе» и в подвале |
| **Идентификация по возрасту** | Обязательное использование крупных визуальных бейджей с указанием возрастного диапазона для мгновенной фильтрации внимания |
| **Стоимость и расписание** | Цена и расписание интегрированы непосредственно в карточку направления, исключая необходимость перехода на отдельные страницы прайс-листов |
| **Педагоги** | Информация о педагогах вшивается в карточки кружков. Отдельная страница команды не проектируется |
| **Целевое действие** | Приоритетный CTA — «Позвонить». Вторичные — мессенджеры (WhatsApp, Telegram) |

### 4.1. Принцип первого экрана

Первый экран должен содержать ключевую информацию, позволяющую пользователю быстро определить:
* назначение клуба;
* возрастную аудиторию;
* территориальную принадлежность (Западное Дегунино);
* доступные способы записи.

## 8. Требования к интерактивным элементам и состояниям (UI States)

| Элемент | Состояния | Требования |
| :--- | :--- | :--- |
| **Кнопки (CTA и вторичные)** | Default, Hover, Active, Disabled | Чёткая визуальная обратная связь при наведении и нажатии. Состояние Disabled однозначно сигнализирует о недоступности действия |
| **Поля ввода (при наличии)** | Default, Focus, Error, Success | Состояние Error содержит текстовое описание причины ошибки |
| **Бейджи возрастов** | Default, Active (выбранный фильтр) | Высокая контрастность относительно фона, гарантированная читаемость шрифта. Active-состояние визуально отличается от Default |
| **Табы (вкладки документов)** | Active, Inactive | Чёткое визуальное разделение активного и неактивного состояния |
| **Аккордеон** | Свёрнут, Развёрнут | Иконка-индикатор состояния (стрелка или плюс/минус) |
| **Фильтры каталога** | Default, Selected, Disabled | Selected-состояние выделяется акцентным цветом |

## 11. Порядок согласования и внесения правок

### 11.1. Этапы согласования

| Этап | Действие | Результат |
| :--- | :--- | :--- |
| 1 | Исполнитель предоставляет вайрфреймы Главной страницы и Детальной страницы кружка в оттенках серого | Утверждение структуры и UX-логики Заказчиком |

### 11.2. Порядок внесения правок

В стоимость работ входит:
* **один цикл корректировок** после представления wireframe;
* **один цикл корректировок** после представления полного дизайн-макета.

**Циклом корректировок** считается единый перечень замечаний, направленный Заказчиком в письменном виде в согласованный срок.

Дополнительные изменения, выходящие за рамки утверждённой структуры проекта, выполняются отдельно и могут влиять на сроки и стоимость реализации.
